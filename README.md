# DNN-based ASL Parameter Estimation

This repository contains experiments and architectures for estimating Cerebral Blood Flow (CBF) and Arterial Transit Time (ATT) from Arterial Spin Labeling (ASL) MRI signals using Deep Neural Networks.

## Root Files
- **`ddn_asl.ipynb`**: The main presentation notebook containing the complete narrative, conclusions, and evaluation tables of all experiments.
- **`data_gen.py`**: The core simulator script used to generate synthetic ASL signals, apply Buxton modeling, and simulate noise.
- **`reference_baselines.yaml`**: The established project baseline metrics for Bayesian and NLLS estimators used as our fixed comparison targets.

## Directory Structure

### `/scripts`
All python execution scripts have been organized here chronologically by experiment phase:
- **`round1_initial/`**: Scripts from the initial layer/depth sweeps and baseline definitions.
- **`round2_architectures/`**: Scripts for structural ablations (e.g., Temporal Encoders, Asymmetric Heads, etc.).
- **`round3_experiment_G/`**: Scripts for the finalized Experiment G diagnostics, targeted feature ablations, and reduced-PLD tests.
- **`exploratory/`**: Scripts used for verifying noise simulator mechanics and identical-data physics evaluation (Exploratory).

### `/experiments*`
These folders contain the output models (`.pth`), diagnostic tables (`.csv`), and saved prediction arrays (`.npy`) generated by the scripts above:
- **`experiments/`**: Round 1 outputs.
- **`experiments_round2/`**: Round 2 outputs.
- **`experiments_G/`**: Round 3 (Experiment G) outputs, including the final `master_results_G.csv`.

### `/notebooks`
Contains deprecated or secondary Jupyter notebooks (e.g., older noise density tests and untracked drafts).

### `/data_metrics`
Contains miscellaneous `.csv` and `.txt` files generated during intermediate evaluation steps across different rounds (e.g., residuals, SNR curves).

### `/plots`
Visualizations generated during the identifiability analysis and data-generation audits.
